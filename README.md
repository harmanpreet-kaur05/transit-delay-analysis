# Transit Delay Analysis (Python)

This project analyses public transport delay data using Python and identifies patterns in delays.

## Features
- Loads and processes data from CSV files
- Classifies trips as early, on-time, late, or cancelled
- Calculates time differences
- Generates insights on delay patterns
- Analyses impact on passengers

## Technologies Used
- Python
- CSV data processing
- Data analysis

## What I learned
- Working with real datasets
- Data analysis and classification
- Problem solving using logic
